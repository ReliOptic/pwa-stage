# Home Screen install reference audit (2026-11-17)

## Confirmed behaviour and implementation spec

- [Apple's iPhone guide](https://support.apple.com/guide/iphone/iphea86e5236/ios): compact Safari uses More → Share → Add to Home Screen; top/bottom layouts expose Share directly. The confirmation contains site identity, editable name and Open as Web App. Add creates a Home Screen icon; launching it behaves as an app and supports quitting and notifications.
- [WebKit Safari 26 announcement](https://webkit.org/blog/17333/webkit-features-in-safari-26-0/): Open as Web App defaults ON for every website, independently of manifest configuration. Users can explicitly disable it. Preserve manifest/icon identity and status-bar geometry; remove the current display:browser opt-out. The published illustration is a 26 reference, not proof of 27.3 pixel geometry.
- [Google Chrome iOS help](https://support.google.com/chrome/answer/9658361?co=GENIE.Platform%3DiOS&hl=en): Share on the right of the address bar → Add to Home Screen → confirm/edit details → Add. Available web apps launch as apps; other shortcuts open the default browser, not necessarily Chrome. The simulator has no default-browser setting, so its existing Safari bookmark fallback remains an approximation. Google's help does not establish Chrome's exact 27.3 toggle defaults for non-app sites.
- [WebKit 16.4](https://webkit.org/blog/13966/webkit-features-in-safari-16-4/): third-party browsers gained Add to Home Screen support. Implement Chrome's missing Share entry using the shared system confirmation. Use the Safari default in that shared confirmation as an explicit inference, not a verified Chrome 27.3 measurement.
- [Apple release notes](https://developer.apple.com/documentation/safari-release-notes/): 27.3 is currently beta, released November 3, 2026. Do not present a final 27.3 UI as verified.
- [Apple Duo product page](https://www.apple.com/iphone-duo/) describes seamless display/orientation transitions and Split View. Preserve one live guest, document state and existing rail clearance through folding. Device changes must not launch the page from Home. The precise 84pt rail metric and web-app-specific fold lifecycle were not confirmed by these sources.

Downloading privately rather than committing does not resolve the runtime-embedding restriction. Do not fetch or embed that kit.

Apple product images/film are reference candidates at https://www.apple.com/iphone-duo/ and https://www.apple.com/iphone-18/; [website terms](https://www.apple.com/legal/internet-services/terms/site.html) do not supply a licence to extract their artwork for this app. [Trademark guidelines](https://www.apple.com/legal/intellectual-property/guidelinesfor3rdparties.html) restrict Apple-owned icons absent express permission. SF Symbols are not Home Screen application artwork; no approved wallpaper download with suitable runtime terms was established. No assets approved, fetched or embedded; no bypass of licence/sign-in restrictions. An assets:fetch command pretending to provide an approved pack would be misleading. Official runtime assets and reference comparison completeness remain blocked pending appropriate permission and version-identifiable references.
